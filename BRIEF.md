# Rewind City — Codex Build Brief

## What this is

Build **Rewind City**: a dreamy, explorable 1990s American city on a cloudy grey
afternoon, in the spirit of Abyssal Garden (https://github.com/Noniv/abyssal-garden).

Like that project, this is **not** a game. There are no objectives, quests, NPCs,
combat, collectibles or win states. It is a place you drift through in a browser.
Everything is generated by code — no image files, no 3D model files, no audio
files. The deliverable a visitor actually uses is **one single self-contained
HTML file**.

## Deliverable shape (match Abyssal Garden's repo layout)

- `index.html` at the repo root — the whole experience in ONE file: inline CSS
  and inline JS, zero external requests (no CDN, no fonts, no libraries loaded
  from elsewhere). It must work:
  - opened directly as a local file (`file://`) in Chrome/Edge on desktop, and
  - served over HTTP (e.g. GitHub Pages) in desktop and mobile browsers.
- `source/` — the readable, split source (like Abyssal Garden's `source/`
  folder) plus a build script (Node, `npm run build`) that assembles/minifies
  `source/` into the root `index.html`. A visitor never needs the build; only
  contributors do. Provide `npm run build:readable` for an unminified build if
  practical.
- `README.md` — in Abyssal Garden's spirit: what it is, "Try it" (download
  `index.html`, open in Chrome/Edge; nothing to install; works offline), what's
  in the city, controls table, detail levels, how it works, "Make it your own"
  pointing at the `source/` files and a few easy first tweaks (fog color, sky
  color, movement speed), license.
- `prompt.txt` — a plain-text summary of the creative brief for this world
  (setting, mood, contents, constraints), like Abyssal Garden ships.
- `LICENSE` — MIT, Copyright (c) 2026 Avary Cooney.
- `.gitignore` — `node_modules/`, build scratch.

## Technology constraints

- **No external dependencies at runtime.** If a 3D library is used during
  development, it must be inlined/bundled into the single `index.html` by the
  build — but prefer hand-rolled WebGL2 (with a graceful WebGL1/canvas
  fallback message) so the file stays tiny.
- **Do NOT require WebGPU.** Abyssal Garden needs WebGPU + Chrome/Edge; this
  city must also run in mobile Safari, so WebGL is the ceiling.
- **Size budget:** aim for an `index.html` under ~200 KB (Abyssal Garden's is
  ~97 KB). Procedural generation over stored data; canvas-generated textures
  for windows/signs instead of embedded images.
- Works offline once downloaded. No analytics, no network calls.
- Performance: instancing/reused geometry and materials, fog-limited draw
  distance, capped pixel ratio on mobile, Low/Medium/High detail levels like
  the original (auto-picked on first visit, remembered), and automatic
  step-down if the tab struggles. Target a smooth 60 fps on a mid desktop and
  a playable frame rate on a low-end phone.

## The world — an overcast afternoon, 1996

Mood first: **cloudy grey afternoon.** Flat diffuse light, no hard sun shadows,
no golden hour. Heavy soft fog so distant blocks fade into grey mist (the fog
does the job water fog did underwater). Muted, desaturated palette: washed
concrete, faded brick, dull teal, mustard, faded red-brown — a disposable-camera
feeling. Streets are wet but it is not raining: dark asphalt, puddle sheen,
fine drizzle particles drifting down. Because it is gloomy at 3pm, interior
lights are ON: pale fluorescent/yellow windows, a diner and a video store
glowing warm against the grey.

Contents (one explorable district, several blocks, city grid):

- Buildings of varied heights with procedurally generated lit/unlit window
  grids, parapets, AC units; a **water tower** as the landmark silhouette.
- Telephone poles with sagging catenary wires, streetlights, traffic lights,
  chain-link fencing, billboards with **fictional** ads only (e.g. "Frosty
  Cola", "98.5 FM The Wolf"). No real brands or trademarks anywhere.
- Landmark storefronts with readable generated signs: **REWIND VIDEO** (video
  rental), **Starlight Diner** (EAT), **INSERT COIN** arcade down a neon
  pink/cyan alley (the "grotto"), **Groove Merchant** records, a gas station,
  the **Starlight Motel** with a faded sign and an empty pool.
- An empty schoolyard: swing set with swings swaying slightly, basketball hoop.
- An empty parking lot and a large blank drive-in screen.
- Boxy 1990s cars (sedans, hatchbacks, wagons from simple shapes, muted
  colors): some parked, some driving slowly around the block with headlights
  on in the gloom.
- A plane passing far overhead now and then; crows crossing the grey sky.

## Movement and controls (mirror Abyssal Garden)

- Desktop: mouse look (pointer lock after entering), `W A S D` move, `E`/`Q`
  up/down (floating, memory-like movement — no walking physics, no gravity),
  hold `Shift` to move faster, `1`–`6` jump to viewpoints, `Esc` opens the
  menu (controls list, detail level, Resume), `M` sound on/off, `H` perf stats.
- Touch: drag to look; hold one finger to drift forward, second finger for
  faster; tappable viewpoint chips and a menu button.
- Viewpoints: 1 Main Street (facing REWIND VIDEO + water tower), 2 Rooftop,
  3 Arcade Alley (facing the INSERT COIN neon), 4 The Video Store,
  5 Schoolyard / Parking Lot, 6 Motel Pool. Each viewpoint must actually face
  its named place.
- Gentle collision: glide along building faces / stop at them; never go below
  street level or above a sensible ceiling; stay inside the district bounds.

## Sound

Synthesized live with the Web Audio API only — no audio files. Starts on the
enter gesture ("Step outside" button on the start overlay). Muffled distant
traffic hum, soft wind, occasional far-off siren, a distant school bell, a
train horn, crows, faint dripping. Subtle. `M` mutes.

## Start flow

Start overlay over the already-rendering scene: title **Rewind City**,
tagline "an overcast afternoon, 1996", loading indicator while the city
generates, one enter button ("Step outside"), controls summary. The scene
should already be visible (blurred/dimmed) behind it, like the original.

## Process

- Work in a branch and open a pull request against `main`. **Stop at the open
  PR — do not merge.** Muse verifies the PR (reads the files, runs
  `index.html` locally, checks the controls/viewpoints) and will instruct the
  merge afterwards.
- In the PR description, state honestly what was and was not tested (browsers,
  devices, file:// vs served, performance).
- No personal email addresses in commits or files; use the GitHub noreply
  identity.
